👋 Introduzione

LosaTerm · Voip Terminal è un unico strumento portable per Windows che mette insieme tutto ciò che serve ogni giorno a chi lavora con Voice/VoIP/UC: terminale SSH e trasferimenti file, server FTP/SFTP e Syslog, diagnostica SBC vendor-neutral, analisi PCAP con diagramma SIP ladder, simulatore SIP, traduttore di cause code e un cheat-sheet di comandi di debug per i principali vendor.

L'idea: un solo .exe, zero installazione, niente dipendenze (a parte gli strumenti che hai già: PuTTY per l'SSH, Wireshark per il PCAP). Gli strumenti SIP/RTP/TLS/DNS funzionano allo stesso modo che il box sia Cisco, Microsoft Teams, AudioCodes, Ribbon, Alcatel o Asterisk.

Progetto gratuito, nato come hobby ed open source (licenza MIT). Ogni feedback aiuta a farlo crescere — usa il menu ❓ o il modulo sul sito.

📋 Requisiti

  • Necessario Windows 10 / 11 (64 bit)
  • Necessario .NET Framework 4.8 (già presente su Windows aggiornato)
  • Incluso PuTTY — già nello zip, usato per SSH/Telnet e per la Console seriale. Se hai un PuTTY installato in C:\Program Files\PuTTY\ l'app usa quello (così resta aggiornato).
  • Opzionale Wireshark / tshark — per l'analisi PCAP (download)

⚙️ Installazione

  1. Estrai lo zip in una cartella a piacere.
  2. Avvia LosaTermVoip.exe (doppio clic). È portable: nessuna installazione.
L'eseguibile non è firmato digitalmente: Windows SmartScreen può mostrare "App sconosciuta". È normale per un progetto indipendente → Ulteriori informazioni → Esegui comunque. In alternativa, il codice è open source: puoi compilartelo da solo con build.bat.

🖥️ SSH / Telnet e 📁 SFTP / SCP / FTP

SSH e Telnet a schede (richiede PuTTY). SFTP e SCP per i trasferimenti file (usano pscp/scp); l'FTP Browser per navigare un server FTP con download/upload/crea cartella/elimina.

Per SCP verso apparati Cisco IOS ricorda i path tipo flash:file.bin / bootflash: (non ~/), e che serve ip scp server enable e privilegio 15.

🔌 Console seriale

Pulsante 🔌 Serial: console per gateway, SBC e router via porta COM (adattatore USB-seriale). Scegli porta COM e baud (default 9600 8N1, lo standard delle console Cisco) e premi Apri nel tab: la console si apre dentro una scheda di LosaTerm (PuTTY in modalità seriale, embeddato come l'SSH), con la stessa barra 📊 Analizzatore / 📄 Log / ❌ Chiudi.

L'analizzatore funziona anche sulla console seriale: collegando un apparato Cisco IOS, le regole evidenziano in tempo reale le anomalie (interfacce down, reload, NTP non sincronizzato, DSP/PVDM…) mentre digiti.

🖧 Server FTP / SFTP / TFTP / DHCP

Pulsante 🖧 Server, quattro schede:

  • FTP — avvia al volo un FTP server (porta/utente/password/anonimo/sola lettura).
  • SFTP — configura il server SFTP basato su OpenSSH di Windows (installazione, avvio servizio, utente dedicato, condivisione di una cartella). Per l'utente dedicato usa il pulsante 🎲 Genera per una password conforme ai criteri (anche di dominio).
  • TFTP — server TFTP nativo (UDP 69) per provisioning/firmware di telefoni e gateway.
  • DHCP (lab) — server DHCP nativo con opzioni 66/150 (TFTP) per i telefoni.
Il DHCP server è solo per laboratori isolati: su una rete di produzione un secondo server DHCP causa conflitti gravi. Usalo solo su una rete separata e spegnilo a fine test.

🩺 SBC Health (diagnostica trunk vendor-neutral)

Il fiore all'occhiello. Tre strumenti nativi, nessuna dipendenza, validi per qualsiasi SBC/trunk (Teams Direct Routing, AudioCodes, Ribbon, Cisco CUBE, Asterisk…):

SIP OPTIONS

Invia un SIP OPTIONS a host:porta in UDP/TCP/TLS e mostra la risposta + status + tempo. Un 200 OK = trunk attivo (è il check di salute usato anche da Teams).

TLS / Certificato

Si connette in TLS (di solito porta 5061) e mostra CN/SAN, emittente, scadenza, versione TLS e cipher. La scadenza del certificato è la causa #1 di down su Teams Direct Routing.

DNS SRV / A

Risolve i record SRV (priorità/peso/porta/target) e A usando il resolver di Windows. Menu con i servizi pronti: _sip._tcp, _sips._tls, _collab-edge._tls (Cisco MRA), _cisco-uds._tcp, _sipfederationtls._tcp, XMPP, H.323.

📦 PCAP & 🪜 SIP Ladder

Apri un PCAP con 📦 PCAP (usa tshark). Nel tab Ladder ottieni il diagramma SIP come Wireshark.

Filtro chiamate (come Wireshark VoIP Calls)

  • La tendina elenca le chiamate per Call-ID: selezionane una per vederne tutti i messaggi (re-INVITE inclusi). SUBSCRIBE/NOTIFY/REGISTER restano voci separate.
  • 🔗 Gambe — spunta opzionale: oltre alla chiamata, mostra anche le gambe correlate (es. le due tratte di una chiamata via CUCM), come selezionare più call in Wireshark.
  • Le frecce RTP verdi mostrano gli stream media (codec, pacchetti) interlacciati al SIP.

Diagnosi automatica

Selezionando una chiamata, il pannello di destra mostra una diagnosi automatica: esito (200/BYE oppure fallimento con codice e cosa controllare), ringback locale (180) vs early media (183), challenge di autenticazione ripetuti, timeout/nessuna risposta.

📡 Syslog Server

Pulsante 📡 Syslog: server UDP integrato (AudioCodes/Cisco). Configura l'apparato per inviare i syslog all'IP di questo PC sulla porta scelta (se la 514 fallisce usa la 1514). La spunta Solo SIP/Call mostra solo le righe dei messaggi SIP veri, nascondendo il rumore di configurazione.

🧰 Net Tools

Pulsante 🧰 Net: cassetta degli attrezzi di rete in un unico pannello — Ping, Traceroute, Port check (TCP), MTU discovery e NTP check (verifica l'orario di un server NTP — utile perché un clock sbagliato fa scadere/invalidare i certificati TLS dei trunk).

🔀 Simulator (SIP, Cause Code, SDP, Debug Cmds)

SIP Simulator

Costruisce e invia un messaggio SIP (INVITE, OPTIONS, REGISTER…) verso una destinazione, con From auto-popolato dall'IP del PC. Utile per testare la raggiungibilità/reazione di un peer.

Cause Code Translator

Traduci tra Q.850 ⇄ SIP ⇄ H.323 e ottieni significato + "cosa controllare" da un dizionario completo (oltre 40 risposte SIP e 20+ cause Q.850). Es: 488 → codec mismatch; 403 → policy/whitelist.

SDP / Codec Analyzer

Incolla un SDP e ottieni: media IP, codec (rtpmap), direzione (sendrecv/sendonly/recvonly/inactive=hold), DTMF RFC2833, SRTP/crypto, ICE, ptime.

🐞 Debug Cmds

Cheat-sheet dei comandi di debug/logging per 12 vendor (Cisco CUBE/IOS, Cisco CUCM con CLI, Asterisk/FreePBX, AudioCodes, Ribbon, Teams DR, Avaya, Mitel, 3CX, Alcatel OXE/OXO, FreeSWITCH, Cloud UCaaS), con pulsante 📋 Copia.

Alza i livelli di debug solo per la diagnosi e riportali a default a fine analisi: su sistemi in produzione un trace troppo verboso può impattare le prestazioni.

📖 Doc & 🖱️ Drag & Drop

📖 Doc: raccolta di link editabile e categorizzata (CUCM SRND, AudioCodes, ecc.) — doppio clic apre nel browser.

Drag & Drop: trascina un file sulla finestra e scegli cosa farne — PCAP → analizza nel Ladder; trace SDL → TranslatorX; syslog/log → viewer Syslog.

🧰 Menu VoIP — suite diagnostica

Il menu 🧰 VoIP (in alto) raccoglie una suite di strumenti di diagnostica Voice/UC, quasi tutti nativi (eccezione: Cattura LIVE e RTP Player usano tshark/dumpcap di Wireshark).

🩺 SIP Health Check (1-click)

Inserisci un dominio (o sip:utente@dominio) e con un clic esegue in sequenza DNS NAPTR → SRV → A/AAAA → TLS+certificato → SIP OPTIONS, restituendo un report colorato con punteggio 0-100 ed elenco dei problemi. La via più rapida per capire "perché il trunk non va".

🔴 Cattura LIVE → pcap

Scegli l'interfaccia (mostra anche l'IP), imposta un filtro BPF (preset VoIP: 5060/5061/3478/5349 + RTP) e cattura in tempo reale con dumpcap. 🪜 Apri nel Ladder analizza subito la cattura nel diagramma SIP. Richiede Wireshark + Npcap.

🎧 RTP Player & DTMF

Da un PCAP elenca gli stream RTP e ne riproduce l'audio (G.711 µ-law/A-law → WAV): senti subito audio monodirezionale, gap, fruscii. Estrae anche le cifre DTMF (RFC 2833) e salva il WAV.

📡 SIP OPTIONS Monitor

Watchdog continuo di uno o più trunk: invia OPTIONS a intervallo e mostra in tabella live stato, RTT, uptime %, ultimo OK/errore (verde/rosso).

🔑 SIP Registration Live

Registra un account SIP con autenticazione Digest MD5 (gestisce il challenge 401/407: realm/nonce/qop) e mostra l'Expires concesso. Con "Mantieni registrato" fa il refresh automatico; pulsante per de-registrare (Expires 0).

🚀 Generatore traffico (load)

Mini-SIPp: invia OPTIONS/REGISTER a CPS configurabile e conta risposte per codice, timeout e RTT min/avg/max.

🌐 DNS VoIP Analyzer + ENUM

Analizza i record DNS di un dominio SIP: NAPTR → SRV (_sip/_sips) → A/AAAA + TXT/MX/NS, con interpretazione (SIP over TLS/TCP/UDP) e warning sui record mancanti. ENUM: da un numero E.164 risale al SIP URI via e164.arpa.

🛰️ Tester STUN / NAT

Scopre l'IP pubblico riflesso (server-reflexive) e classifica il tipo di NAT (confronto a due server): "cone" (RTP OK con STUN) vs simmetrico (RTP monodirezionale senza TURN/SBC). Utile per Teams Direct Routing / WebRTC.

🔥 Firewall port-check VoIP

Verifica le porte tipiche verso un host/SBC: TCP (5060/5061/3478/5349/443/80/22) con connect, e probe UDP reali (SIP OPTIONS sulla 5060, STUN sulla 3478). Distingue Aperta / Chiusa (RST) / Filtrata (timeout).

🧮 Calcolatori VoIP

Tre calcolatori: banda per codec (G.711/729/Opus… + ptime + overhead L2 + VAD), budget MOS (E-model: delay/jitter/loss → R-factor e MOS) e riferimento QoS/DSCP (EF/CS3/AF31…).

Cattura LIVE e RTP Player richiedono Wireshark/Npcap. Il Generatore traffico e gli strumenti che inviano SIP vanno usati solo su reti/sistemi di cui hai autorizzazione.

🌐 Lingua, layout, feedback

Interfaccia multilingua (IT/EN/FR/DE/ES): menu 🌐 Language → scegli la lingua e riavvia per applicare. Posizione/dimensione finestra e ordine connessioni vengono salvati. Per feedback e donazioni usa il menu ❓ o il sito.

🔧 Troubleshooting

SSH / seriale non parte

putty.exe è già incluso nello zip: assicurati di aver estratto tutto nella stessa cartella dell'exe. Se l'hai cancellato, rimettilo accanto all'exe o installa PuTTY in C:\Program Files\PuTTY\.

PCAP non funziona

Installa Wireshark con tshark e riavvia l'app.

Ladder "Nessun messaggio SIP"

SIP su porta non standard: in Wireshark usa Decode As per assegnare la porta a SIP.

Non vedo le frecce RTP

La cattura potrebbe contenere solo segnalazione (RTP su un altro segmento), oppure l'RTP è su porte non riconosciute.

Syslog: porta 514 occupata

Chiudi con Ferma, usa la 1514 o riavvia il PC (socket orfano).

Connessioni/password

Salvate in %APPDATA%\LosaTermVoip\connections.json, cifrate con DPAPI: valgono solo sullo stesso PC/utente.

👋 Introduction

LosaTerm · Voip Terminal is a single portable Windows tool that brings together everything you reach for daily when working with Voice/VoIP/UC: an SSH terminal and file transfers, FTP/SFTP and Syslog servers, vendor-neutral SBC diagnostics, PCAP analysis with a SIP ladder diagram, a SIP simulator, a cause-code translator and a debug-command cheat-sheet for the main vendors.

The idea: one .exe, no install, no dependencies (besides tools you already have: PuTTY for SSH, Wireshark for PCAP). The SIP/RTP/TLS/DNS tools work the same whether the box is Cisco, Microsoft Teams, AudioCodes, Ribbon, Alcatel or Asterisk.

A free hobby project, open source (MIT license). Every piece of feedback helps it grow — use the ❓ menu or the form on the website.

📋 Requirements

  • Required Windows 10 / 11 (64-bit)
  • Required .NET Framework 4.8 (present on up-to-date Windows)
  • Bundled PuTTY — already in the zip, used for SSH/Telnet and the Serial Console. If you have PuTTY installed in C:\Program Files\PuTTY\ the app uses that one (so it stays updated).
  • Optional Wireshark / tshark — for PCAP analysis (download)

⚙️ Installation

  1. Unzip into any folder.
  2. Run LosaTermVoip.exe (double-click). It's portable: no installation.
The executable isn't code-signed, so Windows SmartScreen may say "unknown app" — normal for an independent project → More info → Run anyway. Alternatively the code is open source: build it yourself with build.bat.

🔌 Main window & connections

The connection list is on the left; the top-right always shows the PC's IP (and the VPN IP if active).

  • + New / Edit / Delete — manage connections (SSH, SFTP, SCP, FTP, HTTP/HTTPS), with a VPN tab (Checkpoint, Fortinet, Windows VPN, Manual).
  • Reordering — move a connection up/down: right-click → ▲ Move up / ▼ Move down, or Ctrl+↑ / Ctrl+↓. The order is saved.
  • Double-click = embedded SSH. SSH ↗ = separate window. Right-click = menu.
  • ❓ menu: Website, Support the project, About.

🖥️ SSH / Telnet and 📁 SFTP / SCP / FTP

Tabbed SSH and Telnet (requires PuTTY). SFTP and SCP for file transfers (via pscp/scp); the FTP Browser to navigate an FTP server with download/upload/make-dir/delete.

For SCP to Cisco IOS devices remember paths like flash:file.bin / bootflash: (not ~/), and that you need ip scp server enable and privilege 15.

🔌 Serial Console

🔌 Serial button: console for gateways, SBCs and routers over a COM port (USB-serial adapter). Pick the COM port and baud (default 9600 8N1, the Cisco console standard) and click Open in tab: the console opens inside a tab of LosaTerm (PuTTY in serial mode, embedded like SSH), with the same 📊 Analyzer / 📄 Log / ❌ Close bar.

The analyzer works on the serial console too: connect a Cisco IOS device and the rules flag anomalies live (interfaces down, reload, NTP unsynced, DSP/PVDM…) as you type.

🖧 FTP / SFTP / TFTP / DHCP Server

🖧 Server button, four tabs:

  • FTP — spin up an FTP server (port/user/password/anonymous/read-only).
  • SFTP — configure the SFTP server based on Windows OpenSSH (install, start service, dedicated user, share a folder). For the dedicated user, use the 🎲 Generate button for a policy-compliant password (incl. domain policy).
  • TFTP — native TFTP server (UDP 69) for phone/gateway provisioning & firmware.
  • DHCP (lab) — native DHCP server with options 66/150 (TFTP) for phones.
The DHCP server is for isolated labs only: on a production network a second DHCP server causes serious conflicts. Use it only on a separate network and stop it after testing.

🩺 SBC Health (vendor-neutral trunk diagnostics)

The flagship. Three native tools, no dependencies, valid for any SBC/trunk (Teams Direct Routing, AudioCodes, Ribbon, Cisco CUBE, Asterisk…):

SIP OPTIONS

Send a SIP OPTIONS to host:port over UDP/TCP/TLS and see the response + status + time. A 200 OK = trunk up (the same health check Teams uses).

TLS / Certificate

Connects over TLS (usually port 5061) and shows CN/SAN, issuer, expiry, TLS version and cipher. Certificate expiry is the #1 cause of Teams Direct Routing outages.

DNS SRV / A

Resolves SRV (priority/weight/port/target) and A records via the Windows resolver. Presets included: _sip._tcp, _sips._tls, _collab-edge._tls (Cisco MRA), _cisco-uds._tcp, _sipfederationtls._tcp, XMPP, H.323.

📦 PCAP & 🪜 SIP Ladder

Open a PCAP with 📦 PCAP (uses tshark). The Ladder tab draws the SIP diagram like Wireshark.

Call filtering (like Wireshark VoIP Calls)

  • The dropdown lists calls per Call-ID: pick one to see all its messages (re-INVITEs included). SUBSCRIBE/NOTIFY/REGISTER stay separate.
  • 🔗 Legs — optional checkbox: also shows the correlated legs (e.g. the two segments of a call via CUCM), like selecting multiple calls in Wireshark.
  • Green RTP arrows show the media streams (codec, packets) interleaved with SIP.

Auto-diagnosis

When you select a call, the right panel shows an automatic diagnosis: outcome (200/BYE or failure with code and what to check), local ringback (180) vs early media (183), repeated auth challenges, timeout/no answer.

📡 Syslog Server

📡 Syslog button: built-in UDP server (AudioCodes/Cisco). Configure the device to send syslog to this PC's IP on the chosen port (if 514 fails use 1514). The SIP/Call only checkbox shows only real SIP message lines, hiding configuration noise.

🧰 Net Tools

🧰 Net button: a network toolbox in one panel — Ping, Traceroute, Port check (TCP), MTU discovery and NTP check (verify an NTP server's time — handy because a wrong clock makes trunk TLS certificates expire/invalid).

🔀 Simulator (SIP, Cause Code, SDP, Debug Cmds)

SIP Simulator

Build and send a SIP message (INVITE, OPTIONS, REGISTER…) to a destination, with From auto-filled from the PC's IP. Useful to test a peer's reachability/reaction.

Cause Code Translator

Translate between Q.850 ⇄ SIP ⇄ H.323 and get meaning + "what to check" from a complete dictionary (40+ SIP responses and 20+ Q.850 causes). E.g. 488 → codec mismatch; 403 → policy/whitelist.

SDP / Codec Analyzer

Paste an SDP and get: media IP, codec (rtpmap), direction (sendrecv/sendonly/recvonly/inactive=hold), DTMF RFC2833, SRTP/crypto, ICE, ptime.

🐞 Debug Cmds

A debug/logging command cheat-sheet for 12 vendors (Cisco CUBE/IOS, Cisco CUCM with CLI, Asterisk/FreePBX, AudioCodes, Ribbon, Teams DR, Avaya, Mitel, 3CX, Alcatel OXE/OXO, FreeSWITCH, Cloud UCaaS), with a 📋 Copy button.

Raise debug levels only for diagnosis and set them back to default afterwards: on production systems an overly verbose trace can impact performance.

📖 Doc & 🖱️ Drag & Drop

📖 Doc: an editable, categorized link collection (CUCM SRND, AudioCodes, etc.) — double-click opens in the browser.

Drag & Drop: drop a file on the window and choose what to do — PCAP → analyze in the Ladder; SDL trace → TranslatorX; syslog/log → Syslog viewer.

🧰 VoIP menu — diagnostic suite

The 🧰 VoIP menu (top bar) groups a suite of Voice/UC diagnostic tools, almost all native (exception: Live Capture and RTP Player use Wireshark's tshark/dumpcap).

🩺 SIP Health Check (1-click)

Enter a domain (or sip:user@domain) and one click runs DNS NAPTR → SRV → A/AAAA → TLS+certificate → SIP OPTIONS in sequence, returning a colored report with a 0-100 score and the list of issues. The fastest way to find out "why the trunk is down".

🔴 Live Capture → pcap

Pick the interface (it also shows the IP), set a BPF filter (VoIP preset: 5060/5061/3478/5349 + RTP) and capture live with dumpcap. 🪜 Open in Ladder analyzes the capture in the SIP diagram right away. Requires Wireshark + Npcap.

🎧 RTP Player & DTMF

From a PCAP it lists RTP streams and plays the audio (G.711 µ-law/A-law → WAV): hear one-way audio, gaps, noise immediately. Also extracts DTMF digits (RFC 2833) and saves the WAV.

📡 SIP OPTIONS Monitor

Continuous watchdog of one or more trunks: sends OPTIONS at an interval and shows status, RTT, uptime %, last OK/error (green/red) in a live table.

🔑 SIP Registration Live

Registers a SIP account with Digest MD5 authentication (handles the 401/407 challenge: realm/nonce/qop) and shows the granted Expires. With "Keep registered" it auto-refreshes; a button de-registers (Expires 0).

🚀 Traffic generator (load)

Mini-SIPp: sends OPTIONS/REGISTER at a configurable CPS and counts responses per code, timeouts and RTT min/avg/max.

🌐 DNS VoIP Analyzer + ENUM

Analyzes a SIP domain's DNS: NAPTR → SRV (_sip/_sips) → A/AAAA + TXT/MX/NS, with interpretation (SIP over TLS/TCP/UDP) and warnings for missing records. ENUM: resolves an E.164 number to a SIP URI via e164.arpa.

🛰️ STUN / NAT Tester

Discovers the reflexive public IP (server-reflexive) and classifies the NAT type (two-server comparison): "cone" (RTP OK with STUN) vs symmetric (one-way RTP without TURN/SBC). Handy for Teams Direct Routing / WebRTC.

🔥 VoIP firewall port-check

Checks the typical ports toward a host/SBC: TCP (5060/5061/3478/5349/443/80/22) via connect, plus real UDP probes (SIP OPTIONS on 5060, STUN on 3478). Distinguishes Open / Closed (RST) / Filtered (timeout).

🧮 VoIP calculators

Three calculators: bandwidth per codec (G.711/729/Opus… + ptime + L2 overhead + VAD), MOS budget (E-model: delay/jitter/loss → R-factor and MOS) and a QoS/DSCP reference (EF/CS3/AF31…).

Live Capture and RTP Player require Wireshark/Npcap. The traffic generator and the SIP-sending tools must be used only on networks/systems you are authorized to test.

🔧 Troubleshooting

SSH / serial won't start

putty.exe is already bundled in the zip: make sure you extracted everything into the same folder as the exe. If you deleted it, put it back next to the exe or install PuTTY in C:\Program Files\PuTTY\.

PCAP doesn't work

Install Wireshark with tshark and restart the app.

Ladder shows "No SIP messages"

SIP on a non-standard port: in Wireshark use Decode As to map the port to SIP.

No RTP arrows

The capture may contain only signaling (RTP on another segment), or RTP is on unrecognized ports.

Syslog: port 514 busy

Close with Stop, use 1514 or reboot the PC (orphan socket).

Connections/passwords

Stored in %APPDATA%\LosaTermVoip\connections.json, encrypted with DPAPI: valid only on the same PC/user.
